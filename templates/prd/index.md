## 📝 如何新增子计划

1. 在 `plan/todo/<计划名>/`（待启动）或 `plan/doing/<计划名>/`（直接进行中）建文件夹
2. 写 `index.md`：背景 / 目标 / 核心流程 / 步骤导航 / 核心差异
3. 每个步骤一个 `步骤N-<名称>.md`（四件套：介绍 / 表结构 / 流程 / 伪代码 Tab）+ 原型图 + 流程图 + 菜单清单
4. 原型 HTML（`> 原型图：\`xxx.html\`` 引用）+ `伪代码/` 目录（`> @tabs 步骤N`）
5. 在本文件对应状态表加一行；交付后 `mv plan/doing/<名> plan/done/<名>` 并在里程碑记录
