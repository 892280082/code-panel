# 功能规格：浮动终端命令抽屉

**功能分支**：`001-floating-terminal-commands`  
**创建时间**：2026-07-30  
**状态**：草案  
**输入**：用户描述："参考/Users/owner/repository/code-panel-demo 把浮动终端这个功能复刻过来。就是预填写命令 点击直接执行！然后增删改 排序。"

## 用户场景与测试 *(必填)*

### 用户故事 1 - 查看并一键执行预填命令 (优先级: P1)

运维/开发人员在浏览日志或 SQL 审核面板时，需要快速执行常用命令（如检查磁盘、查看内存、查看进程等）。用户点击一个命令按钮，系统自动在浮动终端中执行该命令，无需手动输入。

**为何此优先级**：这是功能的核心价值——"预填写命令，点击直接执行"。没有此能力，整个功能无意义。

**独立测试**：可以通过添加一条命令后点击执行，验证终端是否正确打开并执行该命令来独立测试。

**验收场景**：

1. **给定** 面板已打开且有可用命令列表，**当** 用户点击某条命令卡片，**则** 屏幕上出现一个浮动终端面板，并自动执行该命令
2. **给定** 终端已打开且命令正在执行，**当** 用户关闭终端面板，**则** 终端进程被终止，面板消失

---

### 用户故事 2 - 管理自定义命令（增删改）(优先级: P2)

用户可以根据自己的工作需要添加新的快速命令（如自定义的日志查询、服务重启命令等），并可编辑或删除不再需要的自定义命令。

**为何此优先级**：增删改是命令管理的核心操作，但用户可以直接使用系统预设命令，因此优先级低于 P1。

**独立测试**：可以通过创建命令、编辑命令、删除命令的完整 CRUD 流程独立测试。

**验收场景**：

1. **给定** 命令抽屉已打开在"自定义"标签页，**当** 用户点击"+ 新建"并填写名称和命令后保存，**则** 新命令出现在列表中并可点击执行
2. **给定** 存在一条自定义命令，**当** 用户点击该命令的"配置"按钮并修改其内容后保存，**则** 命令内容被更新
3. **给定** 存在一条自定义命令，**当** 用户点击"删除"按钮并确认，**则** 该命令从列表中移除

---

### 用户故事 3 - 排序自定义命令 (优先级: P3)

用户希望将最常用的命令放在列表前面，以便快速访问。

**为何此优先级**：排序是便捷性增强，即使不排序功能也可正常使用。

**独立测试**：可以通过上下移动命令并验证顺序变化独立测试。

**验收场景**：

1. **给定** 存在至少两条自定义命令，**当** 用户点击某命令的"▲"按钮，**则** 该命令在列表中上移一位
2. **给定** 存在至少两条自定义命令，**当** 用户点击某命令的"▼"按钮，**则** 该命令在列表中下移一位

---

### 用户故事 4 - 使用系统预设命令 (优先级: P3)

用户开箱即用地获得一组常用系统命令（磁盘、内存、CPU、网络等），无需自行配置。

**为何此优先级**：预设命令提升首次使用体验，但不是核心功能。

**独立测试**：可以通过切换到"系统"标签页并点击任一预设命令执行来独立测试。

**验收场景**：

1. **给定** 命令抽屉已打开，**当** 用户切换到"系统"标签页，**则** 看到一组预设命令（磁盘空间、内存使用、CPU信息等）
2. **给定** 系统标签页中有预设命令，**当** 用户点击任一预设命令，**则** 终端打开并执行对应的系统命令

---

### 用户故事 5 - 浮动终端按钮常驻 (优先级: P2)

用户可以在应用内的任意页面快速唤出终端或命令抽屉，无需切换到专门的终端页面。

**为何此优先级**：浮动入口是提升操作效率的关键设计，让功能触手可及。

**独立测试**：可以在不同页面（/log、/sql）验证浮动按钮始终可见并可操作来独立测试。

**验收场景**：

1. **给定** 用户在日志页面，**当** 点击绿色圆形浮动按钮，**则** 右侧命令抽屉打开
2. **给定** 用户在 SQL 审核页面，**当** 点击浮动终端按钮，**则** 终端面板居中弹出
3. **给定** 有多个终端会话同时打开，**当** 用户拖动某个终端面板的标题栏，**则** 面板随鼠标移动，释放后位置固定

### 边缘情况

- 当命令内容包含特殊字符（引号、管道、重定向）时如何处理？
- 当自定义命令数量为 0 时，显示空状态提示，引导用户创建
- 当系统预设命令已被删除或不存在时，自动重新注入
- 当终端进程启动失败时，给用户明确的错误提示
- 当同一命令被快速点击多次时，防止创建重复终端会话
- 命令名称和内容的最大长度限制，防止数据溢出
- 关闭浏览器页面时自动清理所有活跃终端会话

## 要求 *(必填)*

### 功能要求

- **FR-001**：系统必须支持用户查看所有可用的预填命令列表，包括系统预设和自定义命令
- **FR-002**：用户必须能够点击命令按钮，一键创建终端会话并自动执行该命令
- **FR-003**：用户必须能够添加新的自定义命令，包含名称（label）、命令内容（command）和可选的工作目录（cwd）
- **FR-004**：用户必须能够编辑已有自定义命令的名称、命令内容或工作目录
- **FR-005**：用户必须能够删除不再需要的自定义命令
- **FR-006**：用户必须能够对自定义命令进行排序（上移/下移），系统应持久化排序结果
- **FR-007**：系统必须提供一组开箱即用的预设系统命令（磁盘、内存、CPU、网络、进程等），这些命令不可编辑或删除
- **FR-008**：系统预设命令在首次读取时自动注入，不覆盖已有的同名命令
- **FR-009**：系统命令数据必须持久化存储，重启后不丢失
- **FR-010**：用户必须能够同时打开多个终端会话，每个会话独立运行
- **FR-011**：用户必须能够对终端面板执行最小化、恢复和关闭操作
- **FR-012**：终端面板必须可拖拽移动，位置应在会话期间保持
- **FR-013**：页面刷新或关闭时，所有活跃终端会话应被清理
- **FR-014**：命令抽屉和浮动终端按钮应在应用的所有页面可用（全局挂载）
- **FR-015**：命令抽屉应在打开时每 5 秒轮询刷新命令列表
- **FR-016**：自定义命令的 label 必须在 1-100 字符之间，command 必须在 1-4096 字符之间
- **FR-017**：系统预设命令的 type 为 'system'，自定义命令的 type 为 'custom'
- **FR-018**：浮动终端按钮和命令抽屉触发按钮的位置应可拖拽调整，并持久化到 localStorage

### 关键实体 *(如果功能涉及数据则包含)*

- **CommandButton（命令按钮）**：表示一条预填命令。属性包括 ID（UUID）、显示名称（label）、命令内容（command）、工作目录（cwd，可选）、类型（system/custom）、创建时间、更新时间。系统预设命令不可编辑删除。
- **TerminalSession（终端会话）**：表示一个正在运行的终端实例。属性包括端口号、关联命令的 label、命令内容、工作目录、最小化状态、屏幕偏移坐标。生命周期由前端 store 管理。

## 成功标准 *(必填)*

### 可衡量的结果

- **SC-001**：用户可以在 2 次点击内从查看命令列表到执行命令（打开抽屉 → 点击命令）
- **SC-002**：命令抽屉在 500ms 内完成打开动画并呈现命令列表
- **SC-003**：终端会话从点击到可见在 3 秒内完成
- **SC-004**：命令 CRUD 操作（增/删/改/排序）的 API 响应时间不超过 200ms
- **SC-005**：用户可以同时打开至少 10 个终端会话而不影响系统稳定性
- **SC-006**：页面关闭时所有活跃终端会话在 1 秒内被清理
