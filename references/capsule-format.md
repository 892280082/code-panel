# 时空胶囊文档规范(capsule-format)

> 「时空胶囊」指令的产物规范。胶囊 = 写进胶囊目录(默认 `~/.code-panel-capsules/`,
> 以 `cp get /api/capsule/config` 的 `data.dir` 为准,用户可能改过)的一个
> **单 MD 文件**或**一个小目录**。面板监听该目录,稳定 3 秒后自动弹卡通知。

## 命名

```
<主题slug>-YYYYMMDD-HHmm.md          # 单文件形态
<主题slug>-YYYYMMDD-HHmm/            # 目录形态
  ├── index.md                       #   入口(必须有)
  ├── 原型xxx.html                   #   原型/配图(可选)
  └── notes/xxx.md                   #   补充笔记(可选)
```

- slug:中文可用(如 `微服务拆分-20260912-1430.md`);**禁止** `/`、`..`、换行、前导 `.`
- 时间取**当时**的本地时间,一次生成不重复利用旧名

## 内容骨架(单文件 index.md)

```markdown
# <一句话主题>

## 结论
<一段话说清这个想法是什么、值不值得做>

## 关键要点
| 要点 | 说明 |
|---|---|
| ... | ... |

## 可行方案
<具体怎么做,分步骤>

## 风险 / 待定
- <不确定的点,留给后续>
```

- mermaid 图直接写 ```mermaid 代码块(渲染页支持)
- 原型 html 放同目录,文中用 `> 原型图:`名字.html` ` 引用(自动内联 iframe)

## 写入纪律(⭐ 面板靠「3 秒无变化」判定完成)

1. **一次性写完整**再落盘:先在内存/临时位置组织好全文,再一次写入目标文件
2. 写完**不要再碰**该文件(不追加、不 touch)—— 持续写入会推迟弹卡
3. 自查:`bash ~/.claude/skills/code-panel/cp get /api/capsule/list`,条目应在 3~4 秒后出现

## 归档后

「归入 wiki」成功(push 通过)后**删除胶囊条目**(`rm` 文件 / `rm -rf` 目录),
胶囊从面板列表消失 = 已归档。失败绝不删源。
