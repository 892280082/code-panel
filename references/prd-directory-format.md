# PRD 目录格式标准

> proj / demo 等项目的 PRD 统一目录格式。**状态 = 目录位置**，移动目录即流转状态。
> ⭐ **模板目录：`../templates/prd/`**（总看板 + plan 三状态 + 子计划四件套 + 原型 + 伪代码），写 PRD 前 `cp -r` 复制即用，禁止自创结构。
> 参考实现：`proj-v3/prd/`（proj 组）、`proj-ark/prd/`（demo 组）。

## 1. 总体结构

```
prd/
├── index.md                    # 总看板（管理所有子计划）
└── plan/
    ├── todo/                   # ⏳ 待启动
    ├── doing/                  # 🔄 进行中
    │   └── <计划名>/           # 子计划 = 一个文件夹
    │       ├── index.md        # 入口：背景/目标/核心流程/步骤导航/核心差异
    │       ├── 步骤1-<名称>.md
    │       ├── 步骤2-<名称>.md
    │       ├── 原型-<页面>.html
    │       └── 伪代码/
    │           ├── index.md
    │           └── 步骤N-<端>-<功能>.ts
    └── done/                   # 📂 已归档
```

## 2. 状态 = 目录位置

| 状态 | 目录 | 流转 |
|------|------|------|
| ⏳ 待启动 | `plan/todo/` | 新子计划先建这里 |
| 🔄 进行中 | `plan/doing/` | 启动时 `mv plan/todo/<名> plan/doing/<名>` |
| 📂 已归档 | `plan/done/` | 交付后 `mv plan/doing/<名> plan/done/<名>` |

## 3. 总看板 index.md 格式

分区固定顺序：

```
# <项目> PRD 总看板（<group>）
> 说明 + 状态=目录位置规则

## 📊 进度统计
> 子计划:待启动 N · 进行中 N · 已归档 N

## 🔄 当前计划（进行中）
| 计划 | 模块 | 优先级 | 阶段 | 定稿 | 伪代码 | 核心实现 | speckit |
|---|---|---|---|---|---|---|---|
| [`<计划名>`](<链接>) <计划名>:<一句话说明> | <模块> | P0/P1/P2 | 阶段一/二 | ✅ 日期 或 ➖ | [伪代码](<链接>) | ➖ | speckit0xx 或 ➖ |

## 📅 计划列表(待启动)
> 伪代码:每个计划一份...speckit:严格规格化产物...**定稿 ✅ = 可直接交给开发客户端走 design-prd spec 开发**。
| 计划 | 模块 | 优先级 | 阶段 | 定稿 | 伪代码 | 核心实现 | speckit |

## 📂 已归档计划
| 计划 | 模块 | 优先级 | 阶段 | 伪代码 | 核心实现 | speckit |
（注意：已归档表无「定稿」列）

## 📝 如何新增子计划
## ✅ 里程碑
```

**表格列头**：
- 进行中 / 待启动：`计划 | 模块 | 优先级 | 阶段 | 定稿 | 伪代码 | 核心实现 | speckit`
- 已归档：`计划 | 模块 | 优先级 | 阶段 | 伪代码 | 核心实现 | speckit`

**优先级**：P0（最急）/ P1 / P2；**定稿**：`✅ 2026-09-01` 或 `➖`。

## 4. 子计划文件夹格式

每个子计划 = `plan/<状态>/<计划名>/`：

| 文件 | 内容 |
|------|------|
| `index.md` | 背景 / 目标 / 核心流程 / 步骤导航 / 核心差异 |
| `步骤N-<名称>.md` | **四件套**：① 介绍 ② 表结构 ③ 流程（文字步骤）④ 伪代码 Tab |
| `原型-<页面>.html` | 原生 HTML 原型（自包含 CSS，供 iframe） |
| `伪代码/` | `index.md`（导航）+ `步骤N-<端>-<功能>.ts`（每功能一文件） |

**原型引用**：步骤 md 里用 `> 原型图：\`原型-xxx.html\``（面板自动内联 iframe）。
**伪代码 Tab**：步骤 md 里用 `> @tabs 步骤N`（面板读 `伪代码/步骤N-*.ext` 生成 Tab 切换）。

## 5. 表格渲染规范（重要）

- **空表 = 表头 + 一个分隔行**，禁止在表格内放「暂无」占位行（会渲染错位）
- 说明文字放**表格外**（引用块 `>`）
- **分隔行只能一行**：渲染器只跳过第 1 个分隔行，重复分隔行会被渲染成 `---` 数据行

```markdown
## 📅 计划列表(待启动)
> （暂无——新子计划先建在 `plan/todo/`）

| 计划 | 模块 | 优先级 | 阶段 | 定稿 | 伪代码 | 核心实现 | speckit |
|---|---|---|---|---|---|---|---|
```

## 6. 链接规范

- 面板**预览 iframe**（`/api/prd/content`）不做链接重写，相对链接会断
- 子计划入口 / 文档链接用**绝对 `/api/prd/view?dir=<绝对路径>&file=<文件名>`**
- 原型 HTML 用 `/api/prd/file/<绝对路径>`（相对引用会自动按目录解析）

## 6.5 代码文件浏览

- `/api/prd/view` 左侧文件列表 = **md + 代码文件**（`.ts/.js/.java/.sql/.py/.sh/...`），伪代码目录能直接点开每个 `步骤N-*.ts` 查看
- 代码文件渲染为深色代码视图（不按 markdown 解析）；`/api/prd/files` 仍只列 md（供面板文件列表）

## 7. 注册到面板（config.json）

```json
{
  "prd": {
    "folders": [
      { "name": "<group>·PRD总看板", "dir": "/<绝对路径>/prd", "group": "<group>" },
      { "name": "<计划名>", "dir": "/<绝对路径>/prd/plan/doing/<计划名>", "group": "<group>" }
    ]
  }
}
```

`group` 字段决定面板侧栏分组（同 `/log` 的分组下拉，只显示当前组文件夹）。
