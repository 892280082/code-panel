# 时空胶囊(记个想法)

> 入口:SKILL.md「指令路由表」· 触发词:时空胶囊 / 记个想法 / 胶囊

胶囊 = 写进全局目录的一篇 MD(或小目录),面板监听并**主动弹卡**通知用户;适合速记突发的思路。面板只负责监听/渲染,写文档完全由你完成。

## 步骤(必须全做)

1. **查胶囊目录**(用户可能改过,别写死):`bash ~/.claude/skills/code-panel/cp get /api/capsule/config` → `data.dir`(默认 `~/.code-panel-capsules/`)
2. **生成文档**,遵守下方格式规范
3. **一次性写完整再落盘,写完不再碰**(不追加、不 touch)—— 面板以「3 秒无变化」判定完成,持续写入会推迟弹卡
4. **自查**:`bash ~/.claude/skills/code-panel/cp get /api/capsule/list`,条目应在 3~4 秒后出现

## 格式规范

### 命名

```
<主题slug>-YYYYMMDD-HHmm.md          # 单文件形态
<主题slug>-YYYYMMDD-HHmm/            # 目录形态
  ├── index.md                       #   入口(必须有)
  ├── 原型xxx.html                   #   原型/配图(可选)
  └── notes/xxx.md                   #   补充笔记(可选)
```

- slug:中文可用(如 `微服务拆分-20260912-1430.md`);**禁止** `/`、`..`、换行、前导 `.`
- 时间取**当时**的本地时间,一次生成不重复利用旧名

### 内容骨架(单文件 index.md)

```markdown
# <一句话主题>

## 结论
<一段话说清这个想法是什么、值不值得做>

## 关键要点
| 要点 | 说明 |
|---|---|
| ... | ... |

## 可行方案
<具体怎么做,分步骤>

## 风险 / 待定
- <不确定的点,留给后续>
```

- mermaid 图直接写 ```mermaid 代码块(渲染页支持)
- 原型 html 放同目录,文中用 `> 原型图：`名字.html` ` 引用(自动内联 iframe)
