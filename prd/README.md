# PRD 模板目录使用说明

> 这是各项目的 **PRD 标准结构模板**。复制本目录到项目 `prd/` 下，按占位符替换即可。

## 目录结构

```
prd/
├── index.md              ← 总看板（复制模板「总看板 index.md」）
└── plan/                 ← 状态 = 目录位置（移动目录即流转）
    ├── todo/             ← ⏳ 待启动
    ├── doing/<计划名>/    ← 🔄 进行中（子计划放这里，目录名 = 计划名）
    │   ├── index.md      ← 子计划入口（背景/目标/核心流程/步骤导航/核心差异）
    │   ├── 步骤N-<名称>.md ← 每步骤一个（四件套 + 原型图 + 流程图 + 菜单清单）
    │   ├── 原型-<页面>.html ← 原生 HTML 原型（自包含 CSS）
    │   └── 伪代码/
    │       ├── index.md  ← 伪代码导航
    │       └── 步骤N-<端>-<功能>.ts ← 代码文件（@tabs 渲染，每功能一个）
    └── done/             ← 📂 已归档
```

## 使用步骤

1. **复制**：`cp -r <skill>/templates/prd/* <项目>/prd/`
2. **总看板**：改 `index.md` 里的项目名/分组，在「进行中」表加你的计划行
3. **子计划**：把 `plan/doing/<计划名>/` 改名，填 `index.md`（背景/目标/核心流程/步骤导航/核心差异）
4. **步骤**：每个步骤一个 `步骤N-<名称>.md`，四件套 + 原型图 + 流程图 + 菜单清单
5. **原型**：`原型-<页面>.html`（自包含样式，步骤 md 里 `> 原型图：\`原型-<页面>.html\`` 引用）
6. **伪代码**：`伪代码/步骤N-<端>-<功能>.ts`，步骤 md 里 `> @tabs 步骤N` 渲染
7. **注册面板**：在 code-panel `config.json` 的 `prd.folders` 加 `{name, dir, group}`

## 关键规范（写 PRD 前必读）

- **状态 = 目录位置**：`todo → doing → done`，移动目录即流转，不改字段
- **步骤文档四件套**：① 介绍(含原型图) ② 表结构 ③ 流程(文字步骤) ④ 伪代码 Tab
- **必备元素**：原型图(HTML) + 流程图(mermaid 配数据结构+文字) + 菜单清单(平台/一级/二级/路由/权限码)
- **代码 = 渲染**：伪代码通过 `@tabs` 在 MD 里渲染展示，不是让用户翻 .ts 文件
- **空表**：表头 + 一个分隔行，禁止占位行/重复分隔行（渲染错位）
- **链接**：面板预览 iframe 用绝对 `/api/prd/view` URL
